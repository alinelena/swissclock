## Keyboard Shortcuts
- **`T`**: Switch between Clock and Stopwatch
- **`Space`**: Start / Stop / Resume Stopwatch
- **`R`**: Reset Stopwatch
- **`D`**: Toggle Digital / Analog mode (in Stopwatch)
- **`F`**: Toggle Fullscreen mode
